# Fresh Harvest

Интерактивный сайт каталога Fresh Harvest: 2.5D-дерево с восемью интерактивными плодами, карточками продуктов и галереей четырех линеек.

## Открыть сайт

**[Посмотреть сайт на GitHub Pages](https://usahelauri.github.io/FreshHarvest/)**

Версия с контактами CollCreat: **[открыть](https://usahelauri.github.io/FreshHarvest/collcreat/)**

Версия с контактами Etcape: **[открыть](https://usahelauri.github.io/FreshHarvest/etcape/)**

## Локальный запуск

Требуется Node.js `>=22.13.0`.

```bash
npm ci
npm run dev
```

Проверка проекта:

```bash
npm test
```

Основной интерфейс находится в `app/`, изображения и брендовые материалы — в `public/`.
